# The Kinetic Mindset — GitHub Pages Website

This is a static, GitHub-ready version of The Kinetic Mindset website by Sudhir Panghaal. It keeps the dark navy + cyan + gold first-design direction and includes the supplied chapters and interactive tools.

## Structure
- `index.html` — homepage
- `chapters/` — Chapters 1–10
- `tools/` — Decision Room, Kinetic Type Quiz, Nine-System Diagnostic, Reader's Toolkit
- `css/style.css` — shared site styling
- `js/main.js` — shared navigation, reveal animation, progress bar and Kinetic Room interactions
- `images/` — supplied book cover and blurb images

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload the contents of this folder to the repository (make sure `index.html` is at the repository root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. GitHub will provide the live Pages address.

## Custom domain
You can later connect a domain you own through GitHub Pages settings.

## Important
All navigation is relative/local, so the site can work on GitHub Pages or another static host without Blogger.
